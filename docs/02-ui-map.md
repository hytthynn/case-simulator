## Постоянные элементы (на всех экранах)

**Верхняя панель:** слева аватар агента + серый бейдж уровня (`/ 1`), на вложенных экранах — `<` назад; справа баланс зелёным `$ 0.81` / `$ 11.74` / `$ 6.52` / `$ 1.30` / `$ 1.04`.

**Нижняя навигация (5 табов):**
`Кейсы` (иконка ящика) · `Инвентарь` (портфель) · `Контракты` (свиток + **красная точка**) · `Игры` (геймпад, зелёный при активном) · `Магазин` (пакет).

**Дополнительные табы:** `КЕЙСЫ / ЧЁРНЫЙ РЫНОК / КАПСУЛЫ` (+ иконка друзей), `ПРОФИЛЬ / ДРУЗЬЯ / КЕЙСЫ / БИТВЫ`, `БУСТЫ / ОФОРМЛЕНИЕ`, `ЕЖЕДНЕВНЫЕ / КОНТРАКТЫ`, `ВАШИ ДРУЗЬЯ / ДОБАВИТЬ / ЗАЯВКИ`.

**Загрузочный экран (фирменный паттерн):** чёрный фон, крупная иконка/превью игры по центру, название CAPS (Orbitron) под ним, короткая оранжевая линия, иногда спиннер `Загрузка…`. Встречается для `РУЛЕТКА`, `КОИНФЛИП`, `БИТВА КЕЙСОВ`, `КРАШ`, `ПАЧИНКО`, `АПГРЕЙДЕР`, `RIDE THE BUS`, `БЛЭКДЖЕК`, `РАЗМЕН`, `КОСТИ`, `МИНЫ`, `СКРЕТЧ-КАРТЫ`, `ОБМЕН`.

**Плейсхолдер «СТАВКИ ЗАКРЫТЫ»:** «Дождитесь начала раунда, чтобы сделать ставку. Ваши предметы и деньги в безопасности, игра скоро начнётся.» + зелёная кнопка `ОТКРЫТЬ ПРИЗОВОЙ СЕЙФ`.

## Расхождения, которые нужно учесть при 1:1

1. Баланс на протяжении видео меняется `$11.74 → $6.52 → $1.30 → $1.04 → $0.81` — это живая демонстрация, а не стартовое значение. Стартовый баланс — вопрос Q-07.
2. Счётчик активных битв меняется `131 → 132 → 127 → 126 → 125` — динамические данные, в реплике берутся из БД.
3. На ряде экранов игры показаны в состоянии «нет ставки» (`$0.00`, `СТАВКИ ЗАКРЫТЫ`) — это валидное состояние, его нужно реализовать, а не считать пустым экраном.
4. На видео часть надписей не читается из-за сжатия/масштаба — использовать `reference/ru-strings.txt` и `reference/i18n-keys.txt` как источник точных формулировок.
5. Уровни на плитках игр частично перекрываются анимацией прокрутки — итоговая таблица level-gates уточняется в Q-05.
