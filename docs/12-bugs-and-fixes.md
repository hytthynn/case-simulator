# 12 · Реестр багов, дефектов и исправлений

> **Правило:** сначала строка здесь (статус `open`), потом исправление, потом `fixed` + коммит + регресс-тест.
> Severity: `critical` (релиз блокирован) · `high` · `medium` · `low`.
> Метки: `visual` · `economy` · `security` · `payments` · `online` · `perf` · `i18n` · `assets` · `docs`.

---

## 1. Формат записи

```
### BUG-XXX · Краткое название
- **Severity:** high | **Метки:** visual, economy | **Статус:** open / in_progress / fixed / wontfix
- **Обнаружен:** дата, окружение, версия
- **Шаги:** 1 … 2 … 3 …
- **Ожидалось:** …
- **Фактически:** …
- **Причина:** …
- **Исправление:** коммит `abc1234`, файлы …
- **Регресс-тест:** `apps/web/tests/e2e/…`
- **Связано:** FR-xx / ADR-xxx / вопрос Q-xx
```

## 2. Известные дефекты / проблемы оригинального APK (НЕ переносить в реплику)

| ID | Проблема в оригинале | Как исправляем в TMA | Статус |

| ORIG-02 | **Загрузочные экраны подолгу висят** (`Загрузка…`, чёрный экран на 04:40 видео); в кадре 07:10 бесконечный `Загрузка.` у иконки кейса | Таймауты + retry + `skeleton` + понятная ошибка; NFR-01 | запланировано |
| ORIG-03 | **Оффлайн-заглушки**: «Подключитесь к интернету, чтобы забрать выплату/деньги/награду», «СТАВКИ ЗАКРЫТЫ» без таймера | Онлайн по умолчанию; при оффлайне — явный баннер + очередь, без потери средств | запланировано |
| ORIG-04 | **AdMob-зависимость**: `loading_ad_interval_minutes=1`, `max_per_day=30`, «посмотрите рекламу, чтобы…»; в TMA недоступно | A-02: бесплатные ежедневные клеймы + XTR-буст «без пауз»; ни одного рекламного SDK | запланировано |
| ORIG-05 | **Google Play Billing / Play Games / FCM / Play Integrity** привязаны к экосистеме Google; в Telegram недоступны | A-01/A-03/A-04/A-05: XTR, Supabase, bot notifications, initData+rate limits | запланировано |
| ORIG-06 | **Фиксированный портрет 576×1280**, на других экранах/Desktop возможны обрезания | Адаптивная сетка + safe-area + центрирование колонки ≤480 px | запланировано |

| ORIG-09 | **Риск IP Valve**: 1:1 ассеты/наименования CS2 | D-03 — принято заказчиком; юридическая проверка R-01 до релиза | открыт (Q-03) |
| ORIG-10 | **Нет provably-fair** у оригинала (судя по отсутствию соответствующих строк/эндпоинтов) | Внедряем commit–reveal + экран проверки (FR/§13 ТЗ) | запланировано |

## 3. Дефекты текущего этапа (документация / разбор)

| ID | Severity | Метки | Описание | Статус |
|---|---|---|---|---|
| BUG-001 | medium | docs | Точные веса дропа внутри кейса не распарсены из Dart AOT; используются официальные вероятности CS2 как interim | **open** → Q-04 |
| BUG-002 | medium | docs | XP-кривая, пороги уровней 1..26 и формула `МАКС. СТАВКА` восстановлены частично | **open** → Q-05 |
| BUG-003 | low | docs | Уровни на плитках игр на видео частично перекрыты прокруткой; 6 гейтов помечены «≈» | **open** → Q-05 |
| BUG-004 | medium | assets | ~15 000 PNG скинов отсутствуют в APK (только 30 bundled); требуется выгрузка CDN | **open** → Q-12 |
| BUG-005 | low | i18n | 953 чистых RU-строк извлечены, но часть значений склеена с соседними при выгрузке строк AOT; требуется вычитка при верстке | **open** |
| BUG-006 | medium | payments | Min/max суммы XTR-инвойса и точная комиссия не подтверждены официальной документацией однозначно | **open** → проверить на этапе 1 |
| BUG-007 | low | docs | Точная актуальная версия Bot API (10.1…10.3 по разным источникам) требует сверки на дату релиза | **open** |
| BUG-008 | medium | security | CSP/`frame-ancestors` для конкретных клиентов Telegram в доках не зафиксированы; нужен тест на iOS/Android/Desktop/Web | **open** |
| BUG-009 | medium | online | При отсутствии живого соперника возможны «пустые» лобби (D-02 запрещает ботов) — нужен UX ожидания и таймаут | **open** → ADR-004 |
| BUG-010 | medium | economy | Прайс XTR для ~25 SKU — interim, не утверждён | **open** → Q-06 |
| BUG-011 | low | security | `@telegram-apps/sdk` не подключён на этапе 1: используется типизированный адаптер `window.Telegram.WebApp` с `isVersionAtLeast()`. Требуется замена при появлении реального TMA-окружения | **open** → Q-01/Q-02, ADR-006 |
| BUG-012 | low | economy | `case_drop_pool` пуст: точные веса дропа и маппинг case→item не восстановлены; `open_case` использует детерминированный fallback по редкости | **open** → Q-04/Q-12 |
