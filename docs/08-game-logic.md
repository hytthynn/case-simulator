## 2. Редкости и веса дропа

| Редкость | Цвет | Вес (доля) | Пример |
|---|---|---|---|
| Consumer / Industrial (Mil-Spec и ниже) | `#B0C3D9` / `#5E98D9` | 0.7992 | серые/синие скины |
| Restricted | `#8847FF` | 0.1598 | фиолетовые |
| Classified | `#D32CE6` | 0.0320 | розовые |
| Covert | `#EB4B4B` | 0.0064 | красные |
| ★ Exceedingly Rare (ножи/перчатки) | `#F5C542` | 0.0026 | knives / gloves |

Сумма = 1.0. Внутри редкости предметы равновероятны (строка локализации «…, все равновероятны.»). Для капсул/сувенирных пакетов — собственные таблицы (`case_drop_pool.kind`).

**StatTrak™:** шанс `0.10` для оружия, где `stattrak_eligible = true`; цена × `2.0`; бейдж `ST` на карточке. `[Q-04]`

**Float:** равномерно в `[items.min_float, items.max_float]`, округление до 3 знаков; от float зависит wear:
`FN 0.00–0.07 · MW 0.07–0.15 · FT 0.15–0.38 · WW 0.38–0.45 · BS 0.45–1.00`.

**Выбор предмета (псевдокод):**
```ts
const v = hmacSha256(server_seed, `${client_seed}:${nonce}`).readUInt32BE(0) / 2**32;
const rarity = pickByCumulativeWeight(v, rarityWeights);          // 0.7992 / 0.1598 / …
const pool   = case_drop_pool.filter(case_id, rarity);
const item   = pool[Math.floor(nextUniform() * pool.length)];
const isST   = item.stattrak_eligible && nextUniform() < item.stattrak_chance;
const floatV = item.min_float + nextUniform() * (item.max_float - item.min_float);
const price  = (item.prices[wear] ?? item.prices.price) * (isST ? 2.0 : 1.0);
```

## 3. Цена открытия

```
cost = (cases.base_price + cases.key_price) × count × (1 - case_discount)
```
- `case_discount = 0.35` при активном `boost.caseDiscount` (строка «35 % скидка на каждый обычный кейс, навсегда»); не применяется к чёрному рынку и капсулам.
- На видео: `Использовать ключ + контейнер: $2.61` для Kilowatt Case, `$7.63`, `$5.22`, `$2.61` в других кадрах.
- `count ∈ {1,2,3,5,6}`; массовое открытие до 200, с `boost.massOpenOverdrive` — до 1000.
- Если баланс < cost → `422 INSUFFICIENT_BALANCE`, показывается `weapon_cant_buy.wav`.

## 4. Продажа и авто-продажа

| Операция | Правило |
|---|---|
| Одиночная | `+price` на баланс, предмет удаляется, `transactions(credit, item_sell)` |
| Массовая | все предметы с `price ≤ max_price` (степпер «до $1»), показывается `ВЫБРАНО N шт. / ИТОГО $X` |
| `autoSellTrash` | предметы ниже **Classified** продаются сразу; Classified+ занимают слот |
| Автооткрыватель | продаёт за **65 %** стоимости (`auto_opener_sell_percent: 65`), интервал **5 мин** (`auto_opener_interval_minutes`), лимит слотов 5, `auto_opener_cap_knife_value: true` |
| Хранилище | предметы теряют `% своей стоимости со временем`, затем исчезают навсегда; `payout_rate` в `vaults` |

## 6. Мини-игры: формулы (interim RTP ≈ 95–97 %, `[Q-04]`)

| Игра | Модель | Выплата | RTP |
|---|---|---|---|
| **Coinflip** | PvP, 50/50, серверный `u32 % 2` | победитель забирает оба набора предметов; `МНОЖИТЕЛЬ 1.94×` при `МИНИМ. 50.00 %` | 0.97 (комиссия 3 %) |
| **Roulette** | red/black 48.65 %, green 2.7 % | ×2 / ×14 | 0.973 |
| **Dice** | `roll over/under target`, шанс = `100/target` | `multiplier = 0.97 / p` | 0.97 |
| **Crash** | общий раунд, `crash = 0.97 / (1 - u)` с защитой от мгновенного краша | cashout по текущему множителю | 0.97 |
| **Mines** | 5×5, `m` мин, последовательные открытия | `mult = Π (25-i)/(25-i-m)` × 0.97 | 0.97 |
| **Towers** | сетка, easy/medium/hard, выбор плитки | множитель по сложности | 0.96–0.97 |
| **Plinko** | 12–16 рядов, биномиальное распределение, корзины | `1.2× / 1.5× / 2.2× / 5× / 10× / 12×` | 0.97 |
| **Pachinko** | поле штифтов, ворота, множители `1м/2м/5м/12` | — | 0.96 |
| **Jackpot** | общий банк, шанс = `ставка / банк` | весь банк победителю | 0.97 |
| **Blackjack** | стандартная колода, дилер до 17 | 3:2 за blackjack, 2× за win | 0.975 |
| **Hi-Lo** | higher/lower, кэшаут на каждом шаге | ×1.94 за шаг | 0.97 |
| **Ride the Bus** | 4 стадии: color / high-low / inside-out / suit | множители 2×/2×/3×/4× | 0.96 |
| **Upgrader** | кольцо шанса (на видео `47.5 % / 2.00×`) | предмет дороже | 0.95 |
| **Trade Up** | 6 предметов одной редкости → 1 выше | по `case_drop_pool` | 0.97 |
| **Trade Down** | 1 дорогой → несколько дешевле | — | 0.97 |
| **Scratch** | 3×3, совпадение N символов | таблица выплат | 0.95 |
| **Cash Clicker** | тапы → виртуальные `$`, суточный лимит | удвоение 1×/день | настраиваемый |
| **Defuse** | 3 провода, один «безопасный» | ×3 | 0.97 |
| **Rush B** | гонка участников, `PHOTO FINISH` | банк | 0.97 |
| **Event Wheel** | 1 бесплатный спин/день, приз меняется ежедневно | `$93,546` на видео — промо-величина `[Q-07]` | настраиваемый |

**Общее:** `МАКС. СТАВКА` ограничивается `level_curve.max_bet` и `entitlements` (`boost.maxBet`); ставка может быть как виртуальными `$`, так и предметами из инвентаря (`stake_items`); `СТАВКИ ЗАКРЫТЫ` между раундами.

## 7. Битва кейсов (PvP, D-02)

| Режим | Правило |
|---|---|
| `classic` | побеждает самая дорогая сумма/самый дорогой предмет; победитель забирает всё |
| `fast` | ускоренные раунды |
| `shared` | общий банк / общие кейсы, дележка по вкладу |
| `reverse` | побеждает **наименьшая** стоимость |
| `clutch` | решает последний кейс |
| `terminal` | сценарий «торговца» (UP-Link) |

- Форматы `1v1`, `1v1v1`; `case_ids[]` 1..N; `max_players`; фильтры по стоимости.
- Каждый слот открывает свои кейсы; `battle_rolls` хранит каждый дроп; `total_value` считается сервером.
- `reverseExample`: «вы ведёте $900 против $50, но соперник выбивает предмет дороже в последнем кейсе» → для `classic`.
- **D-02:**participants — только реальные пользователи. Нет второго → `waiting` → таймаут → `cancelled` + возврат.

## 8. Онлайн-раунды (Crash / Jackpot)

```
coordinator: create game_rounds(seed_hash, state='betting', starts_at=now+20s)
broadcast  : "betting", "countdown", "starting", "tick", "crashed"/"spin", "settled"
RPC        : place_bet (идемпотентно), settle_round (в транзакции)
```
- Результат раунда выводится из `HMAC(server_seed, "round:<id>")`, `seed_hash` опубликован заранее.
- Таймеры серверные; клиент не может ускорить/отменить.
- История: Crash `2.59× / 19.81× / 2.09× / 2.09× / 2.05×`, Jackpot `БАНК $5,165 / $8,171`.

## 10. Контроль RTP и анти-эксплойты

- `rolls` + `transactions` позволяют посчитать фактический RTP по каждому кейсу/игре/периоду; дашборд в админке.
- Алерт при отклонении фактического RTP от целевого более чем на ±3 п.п. за 10 000 роллов.
- Все награды (квест/дейли/реферал/подарок) — через RPC с `idempotency_key`, дублирование невозможно.
- `event_spins` уникален по `(telegram_user_id, spin_date)`, `daily_claims` — по `(user,date,kind)`.
- Любая правка весов/множителей → новый ADR + строка в changelog + пересчёт контрольной выборки.
