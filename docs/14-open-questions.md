## 5. Допущения, принятые до ответов

**D-07 (06.11.2026): допущения ниже введены в действие** — см. ADR-006 и запись `[0.2.0]` в changelog.
Все значения помечены `INTERIM [Q-xx]` в `packages/shared/src/constants.ts`, `supabase/seed.sql` и SQL-миграциях.
Правка любого числа из экономики требует нового ADR и строки в changelog.

Если заказчик не ответил к началу этапа, действуют interim-значения (обязательно пометить в changelog):

| Область | Допущение |
|---|---|
| Вероятности | официальные CS2, StatTrak 10 %, RTP 0.95–0.97 |
| Уровни | `xp(n)=round(1440·n^1.35)`, гейты по `02-ui-map.md` |
| Старт | баланс $10, 3 бесплатных кейса, 1 ежедневный спин |
| XTR | прайс из `09-monetization.md` (interim) |
| Языки | RU 100 %, EN/ES — каркас |
| Модерация | автофильтр + ручная очередь, история 30 дней |
| Ассеты | копирование APK+CDN (D-03), при юридическом отказе — план замены |
| Окружение | Supabase Pro + Railway Hobby/Pro, EU-регион |
