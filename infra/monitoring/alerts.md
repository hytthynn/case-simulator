# Мониторинг и алерты

Пороги из [`docs/10-ops-deploy.md`](../../docs/10-ops-deploy.md) §7. На этапе 1
подключены только `/health` и `/metrics`; остальные дашборды включаются вместе с
Q-01/Q-02 (Railway/Supabase доступы).

| Метрика | Порог | Статус |
|---|---|---|
| 5xx на API | > 1 % за 5 мин | запланировано |
| `GET /health` != 200 | любой failed | **работает** (Railway healthcheck) |
| `/metrics` | scrape без PII | **работает** |
| p95 ролла | > 250 мс | запланировано |
| p95 Realtime | > 500 мс | запланировано |
| `answerPreCheckoutQuery` | p95 > 2 с, любой > 10 с | запланировано |
| `star_payments` в `pending` | > 5 мин | запланировано |
| Фактический RTP | отклонение > ±3 п.п. за 10 000 роллов | запланировано |
| Egress / Storage / MAU | > 80 % лимита | запланировано |

Правила логирования (NFR-11): структурированный JSON + `request_id`, без `initData`,
токенов и ПД, ротация 30 дней. Sentry подключается без PII на этапе 10.
