## 2. Обязательные тест-кейсы

### Экономика
| ID | Кейс | Ожидание |
|---|---|---|
| EC-01 | Открытие с балансом ниже цены | `422 INSUFFICIENT_BALANCE`, баланс не изменился |
| EC-02 | 50 параллельных открытий с разных сессий | ровно 50 списаний, без отрицательного баланса |
| EC-03 | Повтор того же `idempotency_key` | тот же `roll_id`, без повторного списания |
| EC-04 | Двойная продажа одного `item_id` | вторая → `422 ITEM_LOCKED` |
| EC-05 | Цена StatTrak = ×2.0 от цены из снимка | совпадает с `reference/prices.json` |
| EC-06 | Массовая продажа «до $1» | выбраны только предметы ≤ $1, сумма = `ИТОГО` |
| EC-07 | Автооткрыватель офлайн 1 ч | 12 открытий × 5 мин, продажа по 65 %, один `claim` |
| EC-08 | Снимок цены в `rolls.price` не меняется после импорта нового снимка | история стабильна |

### Provably fair
| ID | Кейс | Ожидание |
|---|---|---|
| PF-01 | `sha256(server_seed)` совпадает с опубликованным `seed_hash` | true |
| PF-02 | Пересчёт HMAC с `client_seed:nonce` даёт тот же `roll_value` | true |
| PF-03 | Изменение `client_seed` после ролла не меняет результат | результат из БД |
| PF-04 | Повтор запроса не создаёт новый `nonce` | тот же ролл |
| PF-05 | `Math.random()` отсутствует в игровой логике | линтер зелёный |

### Онлайн (D-02)
| ID | Кейс | Ожидание |
|---|---|---|
| ON-01 | Два реальных аккаунта создают/вступают в битву | оба видят ход в реальном времени |
| ON-02 | Нет второго игрока | статус `waiting`, списания нет, таймаут → `cancelled` + возврат |
| ON-03 | Ботов в лобби нет | проверка логов/БД: все `battle_players` = реальные `telegram_user_id` |
| ON-04 | Чат: сообщение у второго клиента | ≤ 500 мс p95 |
| ON-05 | Crash: результат одинаков у всех участников | сверка `game_rounds.result` |
| ON-06 | Потеря сети во время раунда | после реконнекта UI = серверное состояние |
| ON-07 | Джекпот: 5 ставок, один победитель | банк выдан целиком, RTP в допуске |

### Платежи (test-окружение)
| ID | Кейс | Ожидание |
|---|---|---|
| PAY-01 | Покупка каждого SKU | `pre_checkout` < 10 с, entitlement выдан 1 раз |
| PAY-02 | Дубль `successful_payment` | entitlement не дублируется |
| PAY-03 | `successful_payment` без pending-заказа | товар не выдан, алерт |
| PAY-04 | `refunded_payment` | entitlement отозван |
| PAY-05 | Покупка без принятой оферты | `403`, инвойс не создан |
| PAY-06 | В каталоге нет SKU с валютой | автотест по `sku_catalog` |
| PAY-07 | `restore` после переустановки | покупки восстановлены |

### UI / 1:1
| ID | Кейс | Ожидание |

## 3. Тестовые данные

- `supabase/seed.sql`: 241 кейс, ~15 000 предметов из `reference/prices.json`, `rarity_config`, `sku_catalog`, `level_curve`, `admin_flags`.
- Фикстуры: 10 тестовых пользователей, инвентарь с предметами всех редкостей, баланс $10 000 для e2e.
- `TEST_MODE=true` → детерминированный `server_seed` из env для воспроизводимых снимков (никогда в prod).
- Telegram test-бот + отдельные аккаунты для PvP-тестов.

## 6. Критерии приёмки (12 пунктов, из ТЗ §23)

1. Сверка «экран в экран» по 40 состояниям.
2. Все 241 кейс открываются с корректными редкостью/wear/float/ST/ценой.
3. Все 22 игры реализованы и играбельны; флаг отключает без деплоя.
4. PvP-битва двух **реальных** аккаунтов проходит корректно; ботов нет.
5. Чат/друзья/подарки/рефералы работают между реальными аккаунтами.
6. XTR-покупка в test-окружении: < 10 с, без дублей, возврат отзывает.
7. Нет выдачи без `successful_payment`; нет двойного списания по `idempotency_key`.
8. Provably-fair верификация проходит.
9. NFR-01…NFR-17 выполнены (p95, 60 fps, бандл, доступность).
10. Оферта/18+/`/terms`/`/support`/`/paysupport`/дисклеймер доступны.
11. Документация из раздела 20 ТЗ существует, `AGENTS.md` ≤ 200 строк, `docs-lint` зелёный.
12. Нет секретов в репо, RLS на 100 % таблиц, security-аудит без критичных находок.

**Блокирующие дефекты:** любой `critical`/`high` в [`12-bugs-and-fixes.md`](12-bugs-and-fixes.md) → релиз запрещён.
