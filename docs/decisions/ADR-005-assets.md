# ADR-005 · Ассеты 1:1 и фиксированный снимок цен

- **Дата:** 2026-11-06 · **Статус:** принято (решения D-03, D-04)
- **Связано:** [`03-design-system.md`](../03-design-system.md), [`08-game-logic.md`](../08-game-logic.md), [`01-reverse-engineering.md`](../01-reverse-engineering.md)

## Контекст
Оригинал содержит 241 PNG кейсов, 30 bundled-скинов, 62 звука, 6 шрифтов, `coin.html` (Three.js), 42 служебных изображения; остальные ~15 000 изображений грузятся с `cs2-case-images.fly.dev`. Цены берутся из `/api/prices` (Skinport, 14 945 предметов, обновляются ежедневно). Заказчик выбрал: ассеты 1:1, цены — фиксированный снимок 05.11.2026.

## Рассмотренные варианты
| Вариант | Вердикт |
|---|---|
| Свои нейтральные ассеты | ❌ теряется 1:1 (хотя юридически безопаснее) |
| **Исходные ассеты 1:1** | ✅ D-03 |
| Гибрид (своя графика, исходная структура) | ❌ заказчик выбрал полное совпадение |
| Живое обновление цен | ❌ D-04: нестабильность экономики, внешняя зависимость |
| **Снимок + ручной админ-апдейт** | ✅ D-04 |

## Решение
1. Извлечь из APK: `assets/cases/` (241), `assets/images/` (42), `assets/fonts/` (6), `assets/sounds/` (62), `assets/bundled_images/` (30), `assets/page/coin.html`.
2. Догрузить ~15 000 изображений с CDN по путям `/Skins/`, `/Knives/`, `/Gloves/`, `/Stickers/`, `/Agents/`, `/other/`; проверить юридическую возможность (Q-12).
3. Всё → Supabase Storage `catalog/` + CDN, WebP/AVIF с PNG-фолбэком, immutable `Cache-Control`, ключ = хеш содержимого. Манифест — `reference/asset-manifest.txt`; CI-проверка 404.
4. `reference/prices.json` импортируется в `price_snapshots` (`id = 2026-11-05-skinport`) и `items.prices`. Каждый ролл сохраняет `rolls.price` на момент дропа — история не пересчитывается.
5. Обновление цен — **только** ручная админ-процедура с новым `snapshot_id`, ADR и записью в changelog. Автоматического ежедневного импорта нет.
6. Шрифты Orbitron/Rajdhani переносятся 1:1; проверить SIL OFL и атрибуцию (V-08).
7. `coin.html` (Three.js) портируется в `apps/web/src/features/games/coinflip/Coin3D` без iframe.

## Риски и митигация
| Риск | Митигация |
|---|---|
| **R-01:Valve IP** — изображения и наименования CS2 | Юридическая проверка до релиза (Q-03); дисклеймер «unofficial fan-made, not affiliated»; заранее подготовленный план замены на нейтральные ассеты без изменения механик |
| Egress/Storage при 15k картинок | CDN, WebP/AVIF, lazy-загрузка, виртуализация, лимиты Pro-плана, алерты |
| Расхождение имени файла и `items.id` | `verify-assets.ts` в CI, URL-decode имён |
| Устаревшие цены | Явная метка снимка в UI/админке; процедура обновления |

## Последствия
**Плюсы:** максимальное визуальное совпадение; воспроизводимая детерминированная экономика; история роллов стабильна; нет внешней рантайм-зависимости от чужого API/CDN.
**Минусы:** юридический риск; ручное обновление цен; ~7 MB эталонных кадров + каталог картинок в инфраструктуре.
