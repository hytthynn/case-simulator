# ADR-003 · Монетизация: только XTR, гибрид без продажи валюты

- **Дата:** 2026-11-06 · **Статус:** принято (решение D-01)
- **Связано:** [`09-monetization.md`](../09-monetization.md), [`00-ТЗ.md`](../00-ТЗ.md) §14, риск R-02/R-03

## Контекст
Оригинал монетизируется через Google Play Billing (EUR) + AdMob. Внутри Telegram цифровые товары/услуги **обязаны** продаваться только за Telegram Stars (`XTR`), иначе Mini App недоступна мобильным пользователям (TOS §6.2). Заказчик выбрал гибрид: косметика + отдельные бусты, **без** прямой продажи игровой валюты и **без** влияния на шансы.

## Рассмотренные варианты
| Вариант | Вердикт |
|---|---|
| 1:1 перенос IAP: звёзды → виртуальные `$` и бусты | ⚠️ ближе к оригиналу, но усиливает gambling-фрейминг и риск по TOS §6.2.1 |
| Только «поддержать разработчика» | ✅ безопасно, но теряется магазин 1:1 |
| **Гибрид: косметика + бусты удобства** | ✅ выбрано заказчиком |
| Все три модели в ТЗ, выбор позже | ❌ заказчик уже ответил |

## Решение
- Каталог `sku_catalog` содержит только `kind ∈ {cosmetic, convenience, bundle}`.
- **Запрещены** SKU: «купить $», «купить кейс за деньги», «гарантированный нож», «повысить шанс», вывод/обмен/P2P.
- Бусты меняют только удобство/скорость/доступ/оформление: `quickOpen`, `multiOpen`, `massOpen*`, `autoOpener*`, `xp`, `maxBet`, `caseDiscount`, `vaultSlot`, `betterSupplyDrop`, `stickerRemover`, `noAds`, `unlock.*`.
- AdMob-зависимость (A-02) заменяется бесплатными ежедневными клеймами и бустом «без пауз»; сторонних рекламных/платёжных SDK нет.
- Флоу: `createInvoiceLink(currency:"XTR", provider_token:"", prices:[{amount:N}])` → `WebApp.openInvoice` → `answerPreCheckoutQuery` ≤10 с → выдача **только** после `successful_payment` → `telegram_payment_charge_id` UNIQUE → `refunded_payment` отзывает entitlement.
- `/terms`, `/support`, `/paysupport`, оферта и согласие 18+ **до** первой покупки.

## Последствия
**Плюсы:** минимальный риск блокировки; экономика не зависит от платежей; прозрачные возвраты; платящие и неплатящие имеют одинаковое распределение дропа (проверяется метрикой).
**Минусы:** ниже потенциальный доход, чем при продаже валюты; магазин не полностью 1:1 по составу (визуально и по названиям — 1:1); требуется юридическая проверка формулировок.
**Открыто:** Q-06 (прайс XTR), V-02/V-03 (лимиты и комиссия), Q-14 (замена рекламы).
