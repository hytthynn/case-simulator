> Источник: покадровый разбор `IMG_4385.MP4` + ассеты APK (`assets/flutter_assets/assets/fonts/`, `images/`, `cases/`).
> Эталоны: [`reference/screenshots/`](reference/screenshots/). Все значения ниже — **целевые**, сверяются визуальными снапшотами в CI.

## 1. Общий характер

Тёмный, почти чёрный «CS:GO-инвентарь» стиль: плотные сетки карточек, тонкие разделители, отсутствие скруглений на крупных панелях (радиус 4–8 px), яркие **цветовые полосы редкости** как главный навигационный акцент, оранжевые и зелёные CTA. Текст мелкий, uppercase для заголовков, много числовых данных (цены, проценты, float). Визуальная плотность высокая: на экране 576×1280 одновременно 9 кейсов или 12 предметов.

**Правило 1:1:** сохраняются пропорции, иерархия, подписи, цвета, порядок элементов и характер анимаций. Допускается только адаптивная перестройка сетки под ширину webview и замена системных элементов (status bar) на Telegram-safe-area.

## 4. Сетка и отступы (база 576×1280)

| Параметр | Значение |
|---|---|

| Верхняя панель | 44 px (аватар 28×28 + бейдж уровня 18×16, баланс справа) |
| Нижняя навигация | 56 px + safe-area inset |
| Сетка кейсов | 3 колонки, gap 8 px, карточка ~176×150 |
| Сетка предметов | 3–4 колонки, gap 6 px, карточка ~132×150 |
| Сетка игр | 3 колонки, карточка ~176×124 |
| Радиус карточки | 6 px; у модалок 10 px |
| Толщина полосы редкости | 2–3 px по нижнему краю карточки |
| Тап-таргет | ≥ 44 px (a11y) |

Адаптив: при ширине < 380 px — 2–3 колонки; 380–600 — 3; > 600 (Desktop/Telegram Web) — контент центрируется в колонку ≤ 480 px с сохранением пропорций (не растягивать на весь экран).

## 5. Компоненты

### 5.1 Верхняя панель
`<` (только на вложенных) · аватар агента в круге 28 px · серый бейдж `/ 1` · справа `$ 0.81` зелёным. Фон `bg.base`, нижняя граница `border.subtle`.

### 5.2 Нижняя навигация (5 табов)
Иконка 20 px + подпись 10 px. Активный таб — зелёная иконка/текст. На «Контракты» красная точка `·` при наличии награды. Фон `#101216`, верхняя граница `#282C33`.

### 5.3 Верхние табы
Горизонтальный скролл, активный — белый текст + оранжевое подчёркивание 2 px; неактивный — `#8A909B`.

### 5.4 Карточка кейса
```
┌──────────────┐
│   $2.61      │  ← цена, зелёный, 12px, правый верх
│   [ PNG ]    │  ← изображение кейса, contain, ~110px
│  Kilowatt    │  ← название, 11px, по центру, 1–2 строки
│    Case      │
└══════════════┘  ← оранжевый градиент 2px
```
Бейджи поверх: `ГОТОВО` (зелёный), `ПОЛНО` (оранжевый), `БЕСПЛАТНО`, `СНАБЖЕНИЕ`, `ХРАНИЛИЩЕ`, 🔒.

### 5.5 Карточка предмета
Изображение скина `contain`, бейдж `ST` + wear (`WW`, `FT`, `MW`, `FN`, `BS`) в углу, цена `$0.06 - $2` зелёным, имя 10 px, **цветная полоса редкости** по нижнему краю, зелёная ✓ если выбран.

### 5.6 Кнопки
- Primary: зелёный `#3FBF5F`, текст `#0B0C0E`, uppercase, высота 44, радиус 6, лёгкое свечение.
- Primary disabled: `#2A3A2C` + текст `#5C626C`.
- Danger/Продать: `#8E2B2B` → `#EB4B4B`.
- Premium/купить: золотая `#C9A227` или зелёная с ценой `€4.99` (у нас `★ N`).
- Ghost: прозрачная с обводкой `#282C33`.

### 5.7 Модалки и диалоги
Тёмная карточка `#14161A`, радиус 10, затемнение `.72`, заголовок Orbitron uppercase, тело Rajdhani, кнопки в ряд. Примеры: `МАССОВАЯ ПРОДАЖА` (степпер `− до $1 +`, `ВЫБРАНО 56 шт.`, `ИТОГО $5.54`, сетка превью 3×3, зелёная `ПРОДАТЬ $5.54`), `АВТООТКРЫВАТЕЛЬ`, `СТАВКИ ЗАКРЫТЫ`, `КАК ЭТО РАБОТАЕТ`.

### 5.8 Фильтры
Чипы `Цена ▾ | Редкость | Флоат | A–Z | Тип | ▦`, поисковая строка с лупой, слайдер «Макс. цена», кнопки `Сбросить` / `Готово` (зелёная).

### 5.9 Загрузочный экран (уникальный паттерн)
```
        [ иконка / 3D-превью ]
            НАЗВАНИЕ          ← Orbitron, uppercase, 18px
         ─────────            ← оранжевая линия 48×3 px
           Загрузка…          ← опционально, 11px, #5C626C
```
Используется при входе в любую мини-игру. **Обязателен к переносу.**

### 5.10 Рулетка открытия
Полноширинная горизонтальная лента (canvas), карточки ~120×130 с интервалом 8 px, оранжевый треугольник ▼ по центру сверху, тонкая линия редкости под лентой (меняет цвет при остановке), затемнение по краям (`linear-gradient` fade). Под лентой — кнопка открытия, подпись цены, тумблеры, счётчик кейсов, блок «СОДЕРЖИТ ОДНО ИЗ СЛЕДУЮЩЕГО».

## 6. Анимации

| Сцена | Длительность | Кривая | Детали |
|---|---|---|---|
| Рулетка кейса | 2.8–4.0 с | `cubic-bezier(.12,.8,.2,1)` | 5–7 оборотов ленты, тик-звук на каждую карточку, финальное «дожатие» на 1–2 позиции |
| Появление результата | 250 мс | ease-out | scale 0.92→1 + свечение по редкости |
| Coinflip 3D | 2.2 с | ease-in-out | вращение монеты по Y 12 оборотов, блик, падение |
| Crash | по серверу | linear | график/ракета от 1.00× до crash-точки |
| Джекпот | 4 с | ease-out | вращение кольца, замедление на победном сегменте |
| Plinko / Pachinko | 1.5–3 с | физика | отскоки шара по штифтам |
| Смена таба | 180 мс | ease | fade + translateY 4 px |
| Модалка | 200 мс | ease-out | fade + scale .96→1 |
| Haptic | — | — | impact на открытие/выбор; success/error на результат |

**Degrade:** `prefers-reduced-motion: reduce` → заменить рулетку на мгновенный показ результата (результат уже с сервера), отключить частицы/блюр; на слабых Android — 30 fps и ≤ 40 карточек в ленте.

## 8. Telegram-специфика

```css
:root {
  color-scheme: dark;
  --app-bg: var(--tg-theme-bg-color, #0B0C0E);
  --app-surface: var(--tg-theme-secondary-bg-color, #14161A);
  --app-text: var(--tg-theme-text-color, #E9EBEE);
  --app-hint: var(--tg-theme-hint-color, #8A909B);
  --app-button: var(--tg-theme-button-color, #3FBF5F);
  --app-button-text: var(--tg-theme-button-text-color, #0B0C0E);
  --safe-top: var(--tg-safe-area-inset-top, 0px);
  --safe-bottom: var(--tg-safe-area-inset-bottom, 0px);
  --viewport-h: var(--tg-viewport-stable-height, 100dvh);
}
.shell { padding-bottom: max(8px, var(--safe-bottom)); min-height: var(--viewport-h); }
```
- При `colorScheme=light` — **не инвертировать** принудительно: продукт тёмный по дизайну, но заголовок Telegram красить через `setHeaderColor('#0B0C0E')`, `setBottomBarColor('#101216')`.
- `WebApp.expand()` при старте; `BackButton` синхронен с роутером.
- `HapticFeedback` на ключевые события; `showPopup` для нативных подтверждений (удаление аккаунта, возврат).
- Никаких системных.alert/confirm — только свои модалки или `WebApp.showPopup`.

## 9. Доступность

- Контраст текста на фоне ≥ 4.5:1 (проверить `#8A909B` на `#14161A`).
- Все интерактивные элементы ≥ 44×44 px, видимый focus-visible.
- `aria-label` у иконок, `role="progressbar"` у полос XP/загрузки, `aria-live` для баланса и результата.
- Не передавать информацию только цветом: редкость дублируется текстом/бейджем.
